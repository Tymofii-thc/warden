Screen a Solana wallet, live.

This page runs the same risk heuristics as WARDEN's on-chain oracle (wallet age, transaction velocity, counterparty fan-out, flagged-program interaction) directly against a public Solana RPC, in your browser. No wallet connection, no signing, nothing is sent anywhere but a read-only RPC call.

Hackathon-grade heuristic demo, not a licensed AML/compliance product. The "flagged program" list is an illustrative sample, not a real sanctions or threat-intelligence feed. Do not use this as the sole basis for a real compliance decision.

    how the score works

    Score 0-1000, higher is riskier. <300 ALLOW · 300-699 REVIEW · ≥700 BLOCK. Weights: no reachable history +250 (LOW_HISTORY), age <3d +200 (NEW_WALLET), age 3-14d +80, >80% of activity in the last 24h over 5+ txs +200 (HIGH_VELOCITY), >90% unique counterparties over 5+ sampled txs +180 (MIXER_PATTERN), touches a sample flagged program +300 (MIXER_PATTERN). Same weights as offchain/scorer/scoreEngine.ts and the same thresholds as sdk/src/decision.ts. A failed RPC call renders as UNSCORED, never as a clean result.

    why this exists

    Colosseum's hackathon archive has 38 prior submissions in the "institutional-rails" compliance category and zero of them shipped a finished, working on-chain system - every one we found was explicitly a mockup, a concept, or "scoping phase" by its own description. WARDEN is the same idea, finished: a real Anchor program storing risk attestations on devnet, a real scorer pulling live RPC history, and this page, running the identical scoring logic client-side so anyone can test it without installing anything.
